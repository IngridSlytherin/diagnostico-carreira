Diagnóstico de carreira internacional

Envie seu currículo, responda algumas perguntas e receba um plano do que fazer primeiro para conseguir uma vaga remota no exterior.

O PDF é lido no seu navegador e o currículo não é guardado. Só as respostas das perguntas ficam salvas como rascunho neste navegador. Dados saem do seu computador apenas se você marcar a verificação de inglês (o texto vai para o LanguageTool, sem nome, e-mail, telefone e links) ou informar um usuário do GitHub (API pública do GitHub). As notas vêm de regras visíveis, não de uma IA, e não estimam suas chances de contratação.
